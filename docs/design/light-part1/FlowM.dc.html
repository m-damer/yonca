What is on this Home screen
1Top bar: search, bell with the unread count
2Greeting and one-line summary
3Quick actions: New contact, Log activity, Scan QR, Task
4Overdue: red block, warning icon and the word, Done and Snooze on each task
5Today: "Did it happen?" prompt, then tasks and meetings
6Upcoming: next 7 days, View all opens the Calendar
7To complete: contacts with a filled temporary note
8Needs attention: top 3 past their inactivity limit
9Recent contacts: last 6 (long-press for WhatsApp and Call)
10Pipeline: count per stage, USD and SYP totals kept separate
11Targets: top 3 with progress and days left (optional)
12Recent activity: last 8, View more opens the Timeline
13Add button and the bottom bar stay fixed on the screen
Sections with nothing in them are hidden, and each can be switched off and reordered in Settings. Every item has the same word, icon and colour rules as before: nothing is shown by colour alone. Frosted cards need a calm background, so there is a high-contrast mode that turns them solid.
